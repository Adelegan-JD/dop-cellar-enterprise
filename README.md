
# DopCellar Merit Global Limited

DopCellar Merit Global Limited is a Nigerian engineering and infrastructure company delivering electrical, security, automation, and industrial technology solutions for banks, commercial real estate, industry, and government sectors. This repository contains the company’s corporate website, built as a modern, responsive marketing site with a polished user experience.

## Overview

The website showcases the company’s services, products, industries served, completed projects, and contact information. It is designed to present DopCellar Merit as a trusted technology and infrastructure partner while making it easy for customers to get in touch.

## Key Features

- Modern, responsive landing page and multi-page marketing experience
- Dedicated sections for services, products, industries, projects, about, and contact
- Product catalog with category-based filtering
- WhatsApp-enabled inquiry flow for sales and consultation requests
- Smooth animations and polished UI components
- Health check endpoint for deployment and monitoring

## Tech Stack

- React 19
- TanStack Start
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui components
- Docker and Vercel deployment support

## Project Structure

- [src/routes](src/routes) – page routes and API endpoints
- [src/components](src/components) – reusable layout, sections, and UI components
- [src/config](src/config) – site content, navigation, and company information
- [src/assets](src/assets) – branding and product images
- [scripts](scripts) – utilities for content and image processing
